# 大观园 · 本地个人学习版

一个纯本地运行的考研数学刷题 Web 应用：无第三方依赖、无 npm、无需联网，Python 标准库启动，题库 / 知识图谱 / 练习记录全部存本地。

> 本仓库只包含本地应用的代码与必要的运行数据快照。原始题库抓取、证据文件与镜像资源不随仓库分发。

## 功能

| 功能 | 说明 |
| --- | --- |
| 题库 | 6,419 道去重题目；完整题单 5,308、严选 985、真题 1,335、模拟 724（题单间有重叠） |
| 选题与搜索 | 目录子树、科目、题型与个人状态筛选；年份 / 来源 / 正文搜索，`#题号` 精确查询 |
| 练习 | 本地 KaTeX 公式渲染，答案与解析分别展开；选择题自动判定，主观题自行标记 |
| 掌握地图 | 全题库方块视图，四种掌握状态、收藏与笔记筛选，点击回到原题 |
| 收藏与笔记 | 本地持久保存，导入导出 |
| 错题复测 | 不熟练 / 不会进入错题队列，次日到期，掌握后移出 |
| 知识图谱 | 3 学科、23 章节、387 个知识点目录；内置 151 个知识点正文与 1,500 条原 TeX 公式 |
| 智能组卷 | 标准卷 22 题规则组卷；自定义范围与题量，可打印 |
| 学习记录 | 作答历史、收藏与掌握状态变化，分页前排序 |
| 首页统计 | 考试倒计时、今日作答、连续作答天数、年度作答热力图 |
| 主题与备份 | 浅色 / 深色主题；JSON 导出与合并导入，导入前自动备份 |

## 快速开始

需要 Python 3.10+，无任何第三方包。

- Windows：双击 `启动大观园.cmd`
- 其他 / 命令行：

```bash
python server.py 3101 --open
```

- 学习入口：<http://127.0.0.1:3101/math>
- 镜像首页：<http://127.0.0.1:3101/>

服务仅监听本机；重复启动会拒绝已被占用的端口。

## 目录结构

```
server.py            HTTP 服务入口（标准库实现）
local_app.py         学习功能核心逻辑（题库、练习、收藏、组卷等）
app/                 前端（原生 JS + CSS + 本地 KaTeX）
app/data/            知识图谱正文与目录数据
mirror/              原站静态页面快照（未登录态）与本地 API 数据夹具
scrape/              题库快照 JSON（complete / exam / mock）
scripts/             数据恢复、审计与自检脚本
tests/               单元测试（33 项）
user-data/           本地学习数据库（learning.sqlite3，运行时生成）
```

## 数据与设置

- 学习数据：`user-data/learning.sqlite3`，刷新或重启保留。
- 通过「通用设置 → 学习记录与题单」导出 JSON；导入幂等，旧状态不会覆盖较新状态。
